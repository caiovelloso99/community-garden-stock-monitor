# 🌱 Monitoramento de Estoque para Horta Comunitária

Sistema em desenvolvimento para ajudar a reduzir o desperdício de alimentos durante o período de seca, por meio do controle e do monitoramento do estoque de uma horta comunitária.

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)

## 🎯 Sobre o projeto

Na estiagem, a produção de alimentos cai e o desperdício se torna um problema ainda mais sério. Este projeto busca usar tecnologia para organizar o estoque, acompanhar entradas e saídas e apoiar decisões que evitem perdas.

O projeto está alinhado ao **ODS 2 da ONU: Fome Zero e Agricultura Sustentável**.
